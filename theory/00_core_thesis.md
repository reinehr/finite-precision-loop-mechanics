# Core Thesis

This project is built around one mechanism:

> finite precision is not a defect of description; it may be a source of physical structure.

If nature cannot instantiate infinitely precise real numbers, then physical processes must operate with finite distinguishability. Once a system has finite states and deterministic or quasi-deterministic update rules, repeated states and attractor cycles are not exceptional. They are structurally expected.

The proposal is that some of these cycles are not just mathematical artifacts. Some may correspond to stable physical objects.

---

## The Minimal Chain

The core reasoning is:

```text
finite actual information
    -> finite precision
    -> rounding / cut-off
    -> finite state dynamics
    -> attractor cycles
    -> stable loop traps
    -> matter-like behavior
```

The reverse side is:

```text
linear non-trapped process
    -> no closed attractor
    -> no rest frame
    -> light-like behavior
```

Thus the distinction between light and matter is not fundamental substance. It is a distinction between two modes of process.

---

## What Is A Loop Trap?

A loop trap is a stable or metastable cycle in finite process space.

It is not primarily a spatial loop. It is a temporal-process loop:

```text
state A -> state B -> state C -> ... -> state A
```

The word "loop" refers to recurrence in state space. The spatial shape can be a ring, a simplex, a graph, or some other effective coupling topology.

## Why The Schmalznudel Matters

The mass-ratio calculations show that finite Gaussian-ring systems can generate nontrivial attractor spectra. But numbers alone do not explain why a loop would behave like a particle.

The Schmalznudel mechanism is the physical interpretation layer:

- a loop is trapped light-like process;
- self-coupling is a mass-like memory term;
- rounding thresholds create resistance to perturbation;
- rounding residues suggest radiation and decay;
- coupled sub-loops suggest confinement-like behavior;
- potential pressure between loops suggests emergent spatial relations.

Without this layer, the model is mostly a numerical observation. With this layer, it becomes a candidate mechanics.
