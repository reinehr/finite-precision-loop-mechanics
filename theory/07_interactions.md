# Interactions

In this mechanism, an interaction is not a primitive force added to matter. It is a mode of process exchange between loop traps.

The basic idea:

```text
stable loops influence one another through shared inputs, residues, asymmetries, and coupling deformation
```

Different interaction types correspond to different ways loops can affect each other.

---

## Electromagnetic-Like Interaction

A loop can have an internal asymmetry:

```text
one direction, phase, or residue pattern is preferred
```

If this asymmetry emits or absorbs linear processes, it behaves like a charge-like property.

Qualitative mapping:

- same asymmetry -> competition -> repulsion;
- complementary asymmetry -> closure -> attraction;
- mediator is linear -> long range;
- strength falls with relational spreading.

This is not yet a derivation of U(1) gauge theory. It is a process-level picture of how charge-like behavior might arise.

---

## Strong-Like Interaction

Sub-loops may fail to close as isolated attractors but close in combination.

That gives a natural confinement-like picture:

```text
sub-loop alone        -> incomplete attractor
sub-loops together    -> composite attractor
attempted separation  -> stretched process relation
```

If separation injects enough process stress, the system may create new loop pairs rather than isolate the original sub-loop.

This resembles the qualitative logic of confinement:

```text
you do not get a free sub-loop;
you get a rearranged composite system
```

The quark-ratio scans in `evidence/` are numerical evidence that coupled sub-loop periods can produce nontrivial structured ratios.

---

## Weak-Like Interaction

A weak-like interaction is interpreted as a transformation of loop type.

Instead of merely attracting or repelling, it changes the internal attractor identity:

```text
loop type A -> mediator-like transition -> loop type B
```

If the mediator is itself a massive loop trap, its range is short:

```text
loop mediator -> unstable -> short-lived -> short range
```

This remains highly speculative. The mechanism only suggests why a transformation interaction would be short-ranged if its mediator is loop-trapped rather than linear.

---

## Gravity-Like Interaction

Gravity is treated as the least direct interaction.

The rough picture:

```text
loops fluctuate
relations between loops fluctuate
large-scale statistical bias appears as attraction
```

This is closer to induced-gravity or fluctuation-based intuition than to a direct force.

In this project, gravity-like behavior is not part of the publication core. It belongs to the later mechanism program.

---

## Interaction Hierarchy

The qualitative hierarchy is:

| Mode | Mechanism | Expected range |
|------|-----------|----------------|
| Linear residue exchange | photon-like | long |
| shared composite closure | strong-like | short |
| loop-type transformation | weak-like | very short |
| relational fluctuation bias | gravity-like | long but weak |

The goal is not to force the Standard Model into the mechanism by analogy. The goal is to identify testable process signatures for each interaction type.

---

## Testable Direction

Future tests should ask:

1. Do loop asymmetries classify into stable charge-like sectors?
2. Do complementary sectors attract or stabilize composites?
3. Do isolated sub-loops fail where composites succeed?
4. Do transformation paths between attractors show mediator-like bottlenecks?
5. Do coupled loop ensembles produce long-range statistical biases?

Until then, the interaction mapping remains a candidate mechanism, not a derived force theory.
